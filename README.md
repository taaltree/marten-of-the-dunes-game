# Marten of the Dunes

**Play: https://taaltree.github.io/marten-of-the-dunes-game/** (desktop browser, keyboard + mouse)

You are a Humboldt marten (*Martes caurina humboldtensis*), a threatened, one-kilogram carnivore,
in the Horsfall dune-lakes section of the Oregon Dunes National Recreation Area. Keep your energy up
by hunting the prey real martens eat and stripping huckleberry and salal. Raid nests in spring and
summer. Escape bobcats by slipping into dense shrubs or up a tree, and think twice before crossing the
open sand where off-highway vehicles ride.

- **Diet:** DNA metabarcoding of Oregon Dunes marten scats (Morfin, Hallerud, Twining & Levi, in prep.)
  and Eriksson, Moriarty, Linnell & Levi (2019), *PLOS ONE* 14: e0214653. Only published values are
  shown in this public version.
- **Terrain:** USGS 3D Elevation Program lidar. Imagery: USDA NAIP (public domain).
- **Engine:** three.js (MIT). Plants and animals are procedurally generated in Blender for this project.

This repository holds only the built game. It is produced by `npm run deploy:pages` from the
(private) source repository. Levi lab, Oregon State University.
